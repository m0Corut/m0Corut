## 🚀 Featured Work

### 🧳 Tourism Agency ERP/CRM *(private)*
An all-in-one operations platform for travel agencies: branch networks, customer records, tour bookings and accounting/finance from a single place.
Data is isolated at the database level with **Supabase Row-Level Security**, on top of a fine-grained **RBAC** model. A hybrid **Next.js App Router** architecture (Server + Client Components) feeds interactive **Recharts** dashboards.

`Next.js` · `Supabase` · `PostgreSQL RLS` · `RBAC` · `Recharts`

### 🪚 KesApp: Parametric Furniture CAD/CAM *(private, in active development)*
A browser-based furniture design and manufacturing engine. Cabinets are placed in a 3D scene and every panel is regenerated to the millimetre, producing workshop-ready output: **cut lists, guillotine sheet nesting, System 32 CNC drilling maps and DXF export**, all guarded by manufacturability checks and a large automated test suite.

`React` · `Three.js / R3F` · `Zustand` · `Vitest` · `Playwright`

### ☁️ CloudBackup: Desktop Backup App *(private)*
A Windows app that silently watches important folders and backs them up to Google Drive in real time.
Custom, fault-tolerant **OAuth2 flow** via a local HTTP server and the system browser; **chokidar** file watching with **MD5 change detection** to skip redundant uploads; **server-side cloning** through the Drive API for moved/copied large files, saving significant bandwidth.

`Electron` · `React` · `Node.js` · `SQLite` · `Google Drive API`

### 🧾 Aktarım Portalı: E-Invoice Management *(private)*
A platform that automates PDF and XML e-invoice handling for SMEs: file conversion, invoice preview, CSV export and storage-quota management.

`Next.js` · `TypeScript` · `Express.js` · `Prisma` · `PostgreSQL`

### 🎙️ Voice-Based Customer Feedback Analysis *(graduation project)*
A device outside a store records spoken customer reviews; **Whisper** transcribes them, **Zeyrek** filters store-related comments and a **BERT** model classifies sentiment. Results are served through a web dashboard on AWS, with authentication and storage on Firebase.

`Python` · `Whisper` · `BERT` · `NLP` · `AWS` · `Firebase`
